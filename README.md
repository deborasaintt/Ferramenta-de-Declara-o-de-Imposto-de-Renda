# Ferramenta de Declaração de Imposto de Renda

## Sobre o Projeto

Projeto de criação de uma ferramenta de **Declaração de Imposto de Renda utilizando o Microsoft Excel**, com foco na organização, formatação, validação e proteção das informações.

## Aprendizados

Durante o desenvolvimento do projeto, aprendi e apliquei diferentes recursos do Excel, incluindo:

* Formatação de números, e-mails e telefones;
* Validação de dados para criação de listas suspensas;
* Inserção de links (hiperlinks);
* Alinhamento e organização das informações nas células;
* Ajuste da proporção e tamanho das células sem mover imagens e formas;
* Ocultação de planilhas;
* Proteção de planilhas para evitar alterações indevidas;
* Organização visual da ferramenta para facilitar o preenchimento e a utilização.

## Ferramentas Utilizadas

* **Microsoft Excel**

## Objetivo

Aplicar na prática recursos do Excel para desenvolver uma ferramenta organizada, funcional e segura para auxiliar no preenchimento de informações relacionadas à Declaração de Imposto de Renda.
